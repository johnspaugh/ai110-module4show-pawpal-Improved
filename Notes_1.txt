Using the Mermaid Live Editor
A .mmd file is plain text, so you don't import anything. You copy the text between the editor and the file.

Open mermaid.live.
Copy everything in diagrams/architecture.mmd and paste it into the left "Code" pane, replacing the sample. The diagram appears on the right.
If you edit the diagram in the browser, copy the text back into diagrams/architecture.mmd and save. The file is the required deliverable.
Export the image: in the Actions panel, choose PNG (or SVG) and save it as assets/architecture.png.
Embed it in your README:

![PawPal+ architecture](assets/architecture.png)
Your README currently mentions only the UML files, so you'll want to add that line.

You could also open the .mmd file in VS Code with a Mermaid preview extension. The Live Editor is still the quickest way to get the PNG.
